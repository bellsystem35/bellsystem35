# 🌐 التدقيق الحي للموقع — 2026-09-07

## نطاق الفحص

تمت مراجعة صفحات الموقع المنشورة والمتاحة عبر البحث/التصفح، مع مقارنة النتائج ببنية التوثيق الموجودة في GitHub.

## نقاط إيجابية مؤكدة

- الصفحة الرئيسية تستخدم H1 واضحًا بعنوان خدمات الصرف الصحي ومكافحة الحشرات والعزل في الشارقة.
- الصفحة الرئيسية توضح مسارات الخدمة والمشكلة والمنطقة، وتحتوي روابط إلى قطاعات وخدمات ومناطق.
- توجد صفحة أم للصرف الصحي تربط خدمات التسليك والشفط وتنظيف البالوعات والروائح والصيانة والطوارئ.
- يوجد Area Hub مركزي يضم 15 منطقة في الشارقة.
- توجد صفحات خدمة + منطقة فعلية للصناعية والرولة، وليست مجرد أسماء داخل دليل.
- توجد أدلة مناطق وصفحات خدمة محلية، بما فيها صفحات القرائن وأدلة مناطق الشارقة.
- توجد صفحات محتوى تشخيصية حديثة تدعم رحلة المستخدم بدل الاعتماد على صفحات تجارية فقط.

## نتيجة فحص الصناعية

صفحة الصناعية الحالية تستهدف المنطقة مباشرة وتجمع الصرف الصحي والعزل ومكافحة الحشرات، وتحتوي مسارات منفصلة لتسليك المجاري والشفط والصيانة. لذلك لا يوجد أساس حالي لـ Redirect أو Noindex. القرار: **Keep + Improve**.

الإجراء المقترح: جعلها الصفحة المحلية الأم للصناعية، وربطها من Area Hub، ثم إنشاء صفحات خدمة + الصناعية فقط عندما تكون هناك نية بحث واضحة ومحتوى مختلف فعليًا.

## نتيجة فحص الرولة

صفحة الرولة الحالية تستهدف المنطقة وتجمع الصرف الصحي والعزل ومكافحة الحشرات، مع مسارات للتسليك والشفط والصيانة. لذلك لا يوجد أساس حالي لـ Redirect أو Noindex. القرار: **Keep + Improve**.

الإجراء المقترح: جعلها الصفحة المحلية الأم للرولة، مع منع إنشاء نسخ متعددة متنافسة لنفس عبارة «خدمات BELL SYSTEM في الرولة».

## صفحات الأدلة المتنافسة

يوجد أكثر من دليل مركزي لنفس القطاع، مثل دليل مناطق تسليك المجاري ودليل شفط المجاري وفهرس وايت الصرف الصحي. هذه الصفحات لا تُحذف تلقائيًا؛ يجب إبقاؤها فقط إذا كانت كل واحدة تؤدي وظيفة مختلفة بوضوح.

### القرار

- دليل مناطق تسليك المجاري: **Keep** إذا بقيت وظيفته اختيار منطقة ثم الانتقال إلى صفحة التسليك المحلية.
- دليل شفط المجاري: **Keep** إذا بقيت وظيفته اختيار منطقة لخدمة الشفط/البيارات.
- فهرس وايت صرف صحي: **Review / Potential Merge** لأن النية التجارية قريبة جدًا من دليل شفط المجاري؛ لا يتم Redirect قبل مقارنة الروابط والبيانات والأداء في Search Console.
- المقال الذي يشرح كيفية اختيار صفحة الشفط: **Keep as informational**؛ لا يجب أن ينافس صفحة الخدمة لأنه يشرح بنية التنقل بدل بيع الخدمة نفسها.

## اتساق بنية الخدمات

الصفحة الرئيسية تقدم ثلاثة قطاعات رئيسية: الصرف الصحي، مكافحة الآفات، والعزل. لكن صفحة «خدماتنا» تعرض أيضًا السباكة كقطاع رئيسي. لا يتم فرض حذف السباكة أو إضافتها للرئيسية قبل مراجعة صفحة السباكة والروابط الحالية.

القرار المرحلي: **Keep current content + architecture review**، مع منع إنشاء صفحات سباكة محلية جديدة بكميات كبيرة حتى يتم حسم مكان السباكة في بنية الموقع.

## الأسعار تحتاج حوكمة

صفحة منتج تسليك المجاري تعرض سعر بداية 200 درهم للحالات البسيطة، بينما صفحات أخرى/المتجر تعرض خدمات وأسعارًا مختلفة. يجب التأكد من أن كل سعر حالي حقيقي ومحدث ومتطابق بين صفحة المنتج والمتجر والإعلانات قبل استخدامه في Schema أو Ads.

## Sitemap وrobots.txt

لم يتم اعتماد نجاح XML Sitemap أو robots.txt من هذا التدقيق وحده. يجب فحص العناوين الفعلية داخل WordPress/Search Console والتأكد من أن Sitemap المصدر الأساسي هو المستخدم وأن الصفحات المهمة ليست محجوبة.

## Schema

يجب فحص HTML النهائي لكل نوع صفحة للتأكد من عدم وجود LocalBusiness/Service/FAQ/Breadcrumb مكرر من الكود اليدوي وإضافة SEO أو WooCommerce.

## WooCommerce / صفحات المنتجات

المنتجات تستخدم كمسار حجز/طلب، وهذا يختلف عن صفحات الخدمة. يجب التأكد من عدم تحويل صفحات المنتجات إلى بديل كامل لصفحات الخدمات أو جعلها تنافس صفحات الخدمة على نفس الكلمات التجارية.

## أولويات الإصلاح

**P0 — قبل الحملات:**
- توحيد الأسعار المنشورة.
- التحقق من التحويلات Phone/WhatsApp/Form.
- مراجعة Canonical وNoindex للمنتجات والأرشيفات غير المطلوبة.

**P1 — SEO:**
- تثبيت Area Hub واحد كمركز جغرافي أساسي.
- ضبط علاقة Hub → Service → Area.
- مراجعة الأدلة المتقاربة، خصوصًا شفط المجاري ووايت الصرف الصحي.
- مراجعة Schema لكل نوع صفحة.

**P2 — الأداء:**
- قياس Core Web Vitals الحقيقي.
- مراجعة حجم الصور وLCP.
- اختبار الهاتف.

## الحكم الحالي

الموقع لديه بنية محتوى محلية قوية نسبيًا. لا توجد حاليًا أدلة كافية لحذف الصناعية أو الرولة أو تحويلهما. الأفضل هو **Keep + Improve**، مع ضبط Area Hub ومنع إنشاء صفحات متكررة.

ولا ينبغي إعلان اكتمال SEO التقني النهائي قبل تنفيذ الفحوصات الحية داخل WordPress وSearch Console وقياس الأداء والتحويلات.
