- [ ] H1 واحد فقط.
- [ ] عنوان SEO واضح.
- [ ] Meta Description فريدة.
- [ ] Canonical صحيح.
- [ ] محتوى أصلي ومفيد.
- [ ] روابط داخلية تعمل.
- [ ] Schema مناسب وغير مكرر.

- [ ] الصفحة متجاوبة.
- [ ] الهاتف يعمل.
- [ ] WhatsApp يعمل.
- [ ] النموذج يعمل.

- [ ] لا توجد روابط مكسورة.

## الأداء
