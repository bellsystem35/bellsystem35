# قائمة فحص النشر — BELL SYSTEM

## المحتوى

- [ ] Title فريد.
- [ ] Meta Description فريد.
- [ ] H1 واحد.
- [ ] المحتوى يطابق نية البحث.
- [ ] لا يوجد حشو للكلمات المفتاحية.
- [ ] المعلومات التجارية صحيحة ومراجعة.

## SEO التقني

- [ ] Canonical صحيح.
- [ ] الصفحة قابلة للفهرسة.
- [ ] لا يوجد `noindex` غير مقصود.
- [ ] الروابط الداخلية تعمل.
- [ ] الصور مضغوطة ومناسبة، ويفضل WebP عند الإمكان.
- [ ] Alt Text وصفي للصور المهمة.

## Schema

- [ ] Schema يعكس المحتوى الظاهر.
- [ ] لا توجد نسخة مكررة من LocalBusiness أو Service بسبب الإضافة والكود اليدوي.
- [ ] لا توجد تقييمات أو بيانات غير حقيقية.

## التحويلات

- [ ] رابط الهاتف يعمل.
- [ ] رابط WhatsApp يعمل.
- [ ] النموذج يعمل إن وجد.
- [ ] أحداث القياس لا تتكرر بشكل غير مقصود.

## بعد النشر

- [ ] فحص URL في Search Console.
- [ ] التأكد من Sitemap.
- [ ] مراقبة الفهرسة.
- [ ] مراجعة Search Queries بعد توفر بيانات.
