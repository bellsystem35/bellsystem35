# سياسة Redirects — BELL SYSTEM

## الهدف

الحفاظ على قيمة الروابط عند تغيير عناوين صفحات WordPress، ومنع سلاسل التحويل والروابط الميتة.

## قواعد

1. استخدم 301 عند نقل صفحة بشكل دائم إلى عنوان بديل ذي نية بحث مماثلة.
2. لا تحوّل كل صفحات 404 إلى الصفحة الرئيسية؛ يجب اختيار أقرب بديل موضوعي أو إبقاء 404 مفيدة.
3. تجنب Redirect Chains مثل A → B → C؛ الأفضل A → C مباشرة.
4. بعد أي تغيير URL، حدّث الروابط الداخلية وCanonical وSitemap.
5. لا تنشئ Redirect لمجرد تغيير الكلمات المفتاحية إذا كان العنوان الحالي يعمل ولا توجد حاجة حقيقية.
6. اختبر العنوان القديم والجديد بعد النشر.

## سجل التغييرات

لا يُضاف Redirect إلى هذا الملف إلا بعد معرفة المصدر والوجهة وسبب التغيير وتاريخ التنفيذ.
