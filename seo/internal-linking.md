# خريطة الربط الداخلي — BELL SYSTEM

## المبدأ

يعتمد الربط الداخلي على نموذج Hub-and-Spoke: صفحة رئيسية تجمع الموضوع، صفحات خدمات متخصصة، ثم صفحات محلية مرتبطة بالخدمة والمنطقة.

## المسارات الأساسية

```text
الرئيسية
→ الخدمة
→ صفحة المنطقة
→ الخدمة المتخصصة
→ صفحات الأسئلة أو الأدلة ذات الصلة
```

## روابط الخدمة

صفحة تسليك المجاري ترتبط بصفحات الصرف الصحي وشفط البيارات وتنظيف البالوعات وصفحات المناطق ذات الصلة.

صفحة مكافحة النمل الأبيض ترتبط بمكافحة الآفات وبصفحات المناطق التي تتوفر لها صفحات أصلية.

صفحة مكافحة الحمام والطيور ترتبط بصفحات الشبك والأشواك وحماية المكيفات وبالصفحات المحلية المناسبة.

## نصوص الروابط

استخدم Anchor Text طبيعيًا ومحددًا، مثل:

- تسليك مجاري الشارقة
- شفط البيارات في الشارقة
- مكافحة النمل الأبيض
- مكافحة الحمام والطيور

لا تستخدم نفس النص في كل رابط، ولا تضف روابط لا تخدم سياق الصفحة.

## قواعد الجودة

- لا توجد روابط إلى صفحات 404.
- لا توجد روابط مكررة بكثافة في نفس المقطع.
- كل صفحة مهمة يمكن الوصول إليها من صفحات أخرى ذات صلة.
- الروابط لا تستبدل المحتوى المفيد.
- بعد تغيير Slug يجب تحديث الروابط أو إعداد Redirect مناسب.
