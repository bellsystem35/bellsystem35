# Google Search Console — BELL SYSTEM

## قائمة الفحص

- ملكية الموقع مؤكدة.
- Sitemap الموقع الرسمي مضافة.
- الصفحات المهمة قابلة للزحف.
- لا يوجد `noindex` غير مقصود.
- Canonical صحيح.
- لا توجد أخطاء 404 للروابط الداخلية المهمة.
- راقب صفحات الخدمات والصفحات المحلية كل فترة.

## URL Inspection

عند نشر صفحة مهمة، افحص عنوان URL وتحقق من:

1. إمكانية وصول Google للصفحة.
2. حالة الفهرسة.
3. Canonical الذي اختاره Google.
4. أي مشاكل مرتبطة بالزحف أو المحتوى.

## قراءة البيانات

راقب:

- الاستعلامات التي تجلب الظهور.
- الصفحات التي تحصل على النقرات.
- CTR.
- متوسط الموضع كإشارة تحليلية، وليس كضمان للترتيب.
- فروقات الأداء بين صفحات الخدمات والمناطق.

## التحسين المستمر

إذا ظهرت صفحة بانطباعات مرتفعة ونقرات منخفضة، راجع Title وMeta Description ومدى تطابقهما مع نية الباحث. إذا كانت الصفحة لا تحصل على ظهور، راجع الفهرسة والنية والمحتوى والربط الداخلي قبل إضافة كلمات مفتاحية عشوائية.
