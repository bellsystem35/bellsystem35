## النموذج الاستراتيجي

الموقع الرسمي `https://bellsystem35.com/` هو المصدر التجاري الأساسي. GitHub يوثق الهيكل والاستراتيجية والمحتوى المساند، ولا يستبدل صفحات WordPress المنشورة.

### التسلسل المستهدف

`الرئيسية → مراكز الخدمات → صفحات الخدمات → الأدلة المحلية → صفحات المناطق → الروابط الداعمة`

## قواعد منع Cannibalization

- لكل صفحة Primary Intent واضح.
- لا تُنشأ صفحتان تستهدفان نفس الكلمة والنية والموقع الجغرافي دون سبب واضح.
- صفحة الخدمة تستهدف الخدمة، وصفحة المنطقة تستهدف الخدمة + المنطقة عندما يكون المحتوى المحلي أصليًا.
- لا يتم إنشاء صفحات مناطق إضافية لمجرد زيادة عدد الصفحات.
- Canonical يجب أن يطابق الصفحة المنشورة فعليًا.

## أولويات التنفيذ

1. جودة الصفحات الأساسية.
2. محتوى محلي أصلي.
3. ربط داخلي منطقي.
4. Canonical وSitemap وفهرسة صحيحة.
5. Schema غير متكرر ومتوافق مع المحتوى الظاهر.
6. قياس الهاتف وWhatsApp والنماذج.
7. تحسين Google Ads اعتمادًا على Search Terms والتحويلات الفعلية.
8. مراجعة دورية لـCore Web Vitals وتجربة الهاتف.

## مبدأ البيانات

لا تُخترع الأسعار أو العروض أو التراخيص أو المراجعات أو أرقام الاستجابة. أي بيانات تجارية متغيرة يجب أن تؤخذ من المصدر الرسمي الحالي قبل نشرها.
