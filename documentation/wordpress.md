# WordPress وGutenberg | BELL SYSTEM

## طريقة التطوير

يتم تطوير صفحات BELL SYSTEM على WordPress مع الاعتماد على Gutenberg وCustom HTML عند الحاجة.

## معايير الصفحة

- اتجاه RTL.
- تصميم متجاوب.
- تجربة Mobile First.
- H1 واحد.
- عناوين H2 وH3 منظمة.
- أزرار اتصال وWhatsApp واضحة.
- صور WebP محسنة.
- روابط داخلية صحيحة.
- عدم تكرار المحتوى بين صفحات المناطق.

## قبل النشر

```text
المحتوى
↓
التصميم
↓
الروابط
↓
SEO
↓
Schema
↓
اختبار الهاتف
↓
اختبار الكمبيوتر
↓
النشر
```

## Schema

إذا كان Rank Math أو Yoast ينشئ Schema تلقائيًا، يجب عدم إضافة بيانات مكررة دون مراجعة.

## الصور

يفضل تحديد أبعاد الصور واستخدام `loading="lazy"` للصور غير الموجودة في الجزء المرئي الأول من الصفحة.
